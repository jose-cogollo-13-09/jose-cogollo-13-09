## 🩺 Qué hago en Samay

Soy ingeniero móvil en **[Samay](https://samayhealth.com)**. Construyo el software que conecta
**Sylvee**, nuestro dispositivo médico de monitoreo respiratorio, con la app que usan pacientes y
equipos clínicos: desde los bytes que viajan por Bluetooth hasta la pantalla que guía cada respiración.

| | Proyecto | Lo que hace |
|:-:|---|---|
| 📱 | **Samay App** | App Flutter para pacientes: mediciones, maniobras guiadas, notificaciones y sincronización en la nube. |
| 📡 | **samay_ble** | Motor de comunicación con Sylvee: protocolo binario propio, conexión BLE robusta y reconexión automática. |
| 🫁 | **samay_breathing_native** | Plugin FFI que lleva un algoritmo C++ de respiración a Flutter para guiar la maniobra en tiempo real. |
| ✅ | **samay_quality_native** | Plugin FFI con el motor C++ que evalúa la calidad de cada medición directamente en el teléfono. |

<sub>Los repositorios de Samay son privados; aquí cuento de qué tratan.</sub>
